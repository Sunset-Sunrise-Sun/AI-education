# 安全与数据访问规则

## 1. 原则
最小权限、最少收集、显式授权、不绕过学校访问控制。

## 2. 教务系统
只允许处理用户正常登录后本人已有权限查看的数据。

禁止：
- 绕过登录/SSO；
- 破解验证码；
- 越权访问；
- 枚举未授权数据；
- 保存教务密码；
- 未经确认高频请求学校系统。

## 3. 浏览器插件
建议：
- 用户自行完成登录；
- 插件只读取当前页面或页面正常返回的数据；
- 权限尽量最小；
- 同步动作对用户可见；
- 不持久化认证凭据。

## 4. 仓库禁止内容
禁止提交：
- `.env`
- 密码
- API Key
- Cookie / Session / Token
- 未脱敏成绩单
- 可直接识别真实学生的数据

只提交 `.env.example`，且不包含真实值。

## 5. 真实学生材料
用于开发前先脱敏，至少去除姓名、学号、联系方式及其他直接身份标识。

## 6. 停止条件
若任务需要真实密码、Cookie/Session、绕认证、权限不明接口或未授权数据，Agent 必须停止并报告 BLOCKED。
