基线：main c75b6da；2026-10-06。回答只基于仓库及本轮审计。合成演示不是已达成Real LEVEL2/3；模型能力尚未上线。

| 评委问题 | 推荐短答 | 可追溯依据 / 必须保留的限制 |
|---|---|---|
| 为什么不直接用ChatGPT？ | 项目把课程认定依据、课表检查和风险做成可追溯结构，确定性问题不交给自由文本猜测。当前工具编排原型尚未接模型，不宣称优于ChatGPT的实测效果。 | AGENTS、integration/orchestrator、planner；无对比实验 |
| 为什么需要GraphRAG？ | 它可能帮助沿课程与规则关系检索证据，但当前未实现，也不是现有demo依赖。先把有出处的规则和检查做可靠；没有证据就不声称图检索带来收益。 | ARCHITECTURE为建议；无运行中GraphRAG代码证据 |
| 课程认定错了怎么办？ | 模糊等价、身份不清或口径不明保留待确认，按来源和人工决定复核；系统不替代学校正式认定。 | curriculum/matching.py、case_a_decisions；case-owner决定不是官方通用政策 |
| 如何确保方案可行？ | 当前在明确的目标与操作范围内检查已知时间关系和受限换班；未知及非时间规则保留风险/人审。可行标记不是学校可执行或选课成功保证。 | planner/provider、feasibility、section_repair；无全局最优或自动选课 |
| 教学班满了怎么办？ | 容量是快照且规则口径未确认，当前不自动过滤或承诺席位；提示人工核验，不伪造余量。 | provider._pending_non_time；无自造容量阈值 |
| 缺排课时间怎么办？ | 保留UNKNOWN，不能把空meetings理解成没有冲突。当前已有选择可以保留但不等于已认证CLEAR；不擅自新增未知班。 | planner/status、UNKNOWN测试、前端中性文案 |
| 偏好都会生效吗？ | 表单记录结构化Preference，编排原样传入；当前激活偏好的硬软分类/执行口径仍有人审，不保证所有偏好满足。 | planner/provider；无需把“已传入”说成“已执行” |
| 隐私怎么处理？ | 输入按授权在受控本地处理，演示用合成材料，真实学生材料和凭据不入仓库。XLSX入口有限长和安全错误；当前无鉴权，不应作为公开互联网生产API。 | SECURITY、completed_courses_import API；不宣称安全认证/完整部署合规 |
| 学校系统真的接通了吗？ | 有受控读取与验收工具及部分真实材料记录，尚未拿到完整五校区真实输入并完成Real LEVEL2/3；North历史深分页异常仍阻塞。 | READINESS_DECISION_NOTES、REAL_CASE_A_ACCEPTANCE；没有本轮学校访问 |
| 为什么demo部分数据合成？ | 完整真实供给尚不可用，而且公开演示不暴露学生材料。每段说明Mock展示还是Synthetic计算；不假设只有教学班是合成。 | test_synthetic_production_e2e全输入synthetic；默认UI Mock |
| 技术创新在哪里？ | 项目集成了认定不确定性、历史范围和教学班调整，强调受限修复、来源绑定与风险透明；这是系统设计差异，不声称发明了新的求解算法。 | Curriculum/Planner/Store；无研究级性能/新算法证明 |
| 能推广到其他大学吗？ | 模块和契约提供适配边界，但每校培养方案、认定规则、身份映射与数据授权需要重新核验。目前没有第二所学校部署证据。 | plan_profiles、interfaces；不称开箱即用 |
| 还没完成什么？ | 模型理解/检索、通用上传到规划闭环、完整真实学校E2E、全局与跨学期优化、正式容量/通勤/先修/偏好执行、公开部署鉴权和用户效果验证。 | 当前status与源码；完成代码wiring不等于这些能力 |
| 商业/用户价值是什么？ | 目标是减少跨方案核对和排课调整的信息割裂，让学生与指导人员看见依据与风险。尚无付费客户、用户留存或节省时间实测，不提供虚构收入预测。 | 产品定位；真实价值指标待用户试验 |
| XLSX上传后就能得到计划吗？ | 后端有generic已修课程导入入口，但当前页面文件选择未贯通到它，也不注入fixed Case A runtime。演示要分别说明，不能剪辑成完整上传闭环。 | frontend/state/userInput、curriculum输入文档、导入API测试 |
| 近3000测试说明什么？ | 说明指定版本/环境下多类自动回归通过，不等于近3000用户、真实学校准确率或100%覆盖。现场可展示与场景相关的具体证据。 | 6c1353b独立回归2979/2skip；当前main内容一致 |

讲解者答不上来时使用：“这是当前边界，我们没有这项实测证据；已有证据是……”。不要用未来路线图抵消当前未完成项。所有数字在最终视频版本再次核对，私有Case A统计标明来源记录、未经本轮独立重算。

最新Planner补充：已有班替代只评估候选并要求用户选择，不自动换班；changes可为唯一CLEAR required候选的新增。Mode1中的避开时段/连堂调班及风险等级是预置示例，不是当前求解证据。
