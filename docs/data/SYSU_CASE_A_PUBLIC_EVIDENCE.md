## 6. 为什么现有材料不能证明"2025 级正式培养方案"

对 D2 与 D3，现有公开材料都不满足以下**全部**条件，因此不能标记为已取得：

| 条件 | D2（遥感） | D3（网安） |
|---|---|---|
| 是本科培养方案 | ✅（`CURR-OLD-001`）／❌（白皮书） | ❌（硕士方案、课程表都不是） |
| 明确适用 **2025 级** | ❌（2019 级 / 2021 白皮书） | ❌ |
| 是当前有效版本 | ⚠️ 未确认 | ⚠️ 未确认 |
| 含正式课程体系 / 学分要求 | ✅（2019 级方案） | ❌ |
| 有版本号 / 年级 / 生效范围证据 | ✅（年级=2019） | ❌ |

**因此结论是 `Not Found`，而不是"用旧版顶上"。** 本轮**没有**用旧版本或白皮书替代 2025 级正式版本。
