# 数据源登记表（Data Source Registry）

> **状态：已同时登记 Case A 的 `Public Official` 与 `Authenticated Official` 两类来源
> （Phase 2B-0B 公开来源 + Phase 2B-0B+ 认证来源）。**
>
> **已经取得两份认证来源的培养方案副本**（`CURR-OLD-003` 25级 遥感科学与技术 /
> `CURR-NEW-004` 25级 网络空间安全）。但**原始 docx 仅由负责人受控保存，不进入 public Git**；
> 本表只登记其**来源性质**与**必要的结构化事实**。
>
> **硬性规则：本表不得填写未经人工确认的链接或机构信息。** 宁可留空，也不允许写入推测出来的 URL。
>
> **前提：当前 GitHub 仓库是 public（公开）仓库。** 凡可能含个人信息的数据，
> **Raw 与 Sanitized 都不得登记为"可入库"**，只能登记为"经非公开位置交付"。
>
> 本表同时登记两类来源：**`Public Official`**（无需登录即可访问）与
> **`Authenticated Official`**（仅本人正常登录后可见）。两者的**证据等级判定标准一致**，
> 但 `Authenticated Official` 必须注明"外部访问者无法通过公开 URL 独立复核"。

## 1. 用途

1. 让每一个真实数据都有**可追溯的出处**（`/AGENTS.md` 第 18 节）；
2. 记录每个来源的**授权与合规属性**（是否官方、是否公开、是否需要登录、可否入库）；
3. 区分 **Raw / Sanitized / Mock**，避免三者混淆；
4. 记录**证据等级**，防止"找到一个相关网页"就被当成"正式材料已取得"；
5. 明确哪些数据**永远不能进入 public 仓库**。

## 2. 字段定义

| 字段 | 含义 | 填写要求 |
|---|---|---|
| `source_id` | 数据源唯一编号 | 见第 3 节；**一经分配不得复用** |
| 数据类别 | 对应 D1–D5 | 与 `DATA_ACQUISITION_PLAN.md` 编号一致 |
| 来源机构 | 发布该数据的机构 | 必须为**实际确认过**的机构，不得推测 |
| 来源标题 | 文件或页面的正式标题 | 照抄原标题，不改写 |
| 来源 URL / 文件位置 | 官方链接 | **未确认时填「待填写」**；禁止写入推测链接 |
| 是否官方 | 是否为中山大学官方发布 | `是 / 否 / 待确认`；非官方来源必须注明性质 |
| 是否公开 | 无需登录即可访问 | `是 / 否 / 待确认` |
| 是否需要登录 | 获取是否需要本人账号 | `是 / 否`；为"是"时必须注明"**仅限本人正常权限**" |
| 发布时间 / 适用学年 | 文件发布日与适用学年 | 只写文件上确实标注的信息，不推测 |
| 适用专业 / 对象 | 适用于哪些专业或对象 | 用于判断能否用于 Case A |
| 获取日期 | 实际取得数据的日期 | 本轮为**查阅日期**，非下载日期 |
| Raw / Sanitized / Mock | 产出层级与入库判定 | 见 `DATA_ACQUISITION_PLAN.md` 第 5.1 节 |
| **证据等级** | 该来源当前能证明到什么程度 | `Confirmed / Partial / Not Found / Historical / 不适用`（定义见下） |
| **访问类型** | 该来源的访问方式类别 | `Public Official`（公开官方：无需登录即可访问）／`Authenticated Official`（认证官方：仅本人正常登录后可见）。**这是登记元信息，不是公共业务 Schema** |
| 备注 | 限制、脱敏说明、使用条件 | 必须写清"限制"，不能只写"允许" |

### 证据等级定义

| 等级 | 含义 |
|---|---|
| `Confirmed` | 官方来源明确，且**能直接支撑**其声称的用途 |
| `Partial` | 官方来源存在，但**不足以完全支撑**用途（版本不符 / 非制度文件 / 学院转载 / 缺发布日期等） |
| `Not Found` | 在**公开**官方来源中未找到；**不得用其他材料顶替** |
| `Historical` | 官方来源但为**已被取代的旧版**，仅用于版本对照 |
| `不适用` | 来源真实但与 Case A **层次不符**（如研究生方案用于本科场景），明确排除 |

> **「公开性」与「证据真实性」必须分开记录**（本轮新增）：
> **访问类型**回答"这份材料怎么取得、外部能否独立复核"；
> **证据等级**回答"这份材料当前能证明到什么程度"。
> 因此 `Authenticated Official` 来源**同样可以是 `Confirmed`** —— 只要来源真实、内容可核对；
> 但必须**额外注明**"由负责人本人在已有正常权限下取得，
> **外部访问者无法通过公开 URL 独立复核**"。

```text
POLICY-###        政策 / 制度 / 办事说明（D1）

```

规则：编号一旦分配即不复用；作废不删除，在备注写"已作废（原因 + 日期）"；
同一文件的 Raw 与 Sanitized 版本共用同一 `source_id`。
