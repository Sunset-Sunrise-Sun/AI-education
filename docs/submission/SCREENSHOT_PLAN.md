## 一、拍摄前统一规则（每一张都适用）

### 1. 隐私遮挡（硬要求）

| 必须遮挡 / 不出现 | 说明 |
|---|---|
| 姓名、学号、学院、专业、年级、入校时间 | 成绩单上的学生信息区块，**整块不要入镜** |
| 成绩数字、绩点、排名、平均绩点 | 成绩单列与页脚统计行，**不要入镜** |
| 浏览器地址栏、书签栏 | 如需显示地址，只显示 `127.0.0.1` 本地地址 |
| 开发者工具、控制台、网络面板 | 一律关闭 |
| Cookie、Token、请求头、请求体的原始内容 | 任何调试面板都不要入镜 |
| 真实教师姓名 | 涉及真实教学班的画面，如出现教师姓名需打码或裁掉该列 |
| 桌面其他窗口、通知、聊天软件 | 截图前清理桌面与通知中心 |

### 2. 必须保留的披露（不得裁掉、不得覆盖、不得折叠）

- **数据范围说明**：南校园 + 深圳校区，及"全校完整学期数据：否"这类标注；
- **"排课信息待核验" / "教师信息暂未同步"** 这类状态标签；
- **各区块内的待确认事项**及其说明文字

> 这些披露是本项目的可信度证明。⛔ 为了画面好看而裁掉它们，等于自己拆掉最强的论据。

### 3. 画面统一要求

- 统一分辨率与缩放（建议 1600 宽，浏览器缩放 100%）；
- 统一主题（浅色），避免有的图深色有的图浅色；
- 统一演示数据（同一份成绩单、同一个学期、同一组偏好），保证跨图数字一致；
- 画面里出现的任何数字，都要能在 `MATERIAL_FACT_CHECK.md` 里找到对应条目。

### 4. 拍摄顺序建议

按页面从上到下、按演示流程顺序拍，这样跨图的数字天然一致：

```text
成绩单上传 → 培养要求识别 → 当前课表与偏好 → 学业方案总览 → 本学期推荐课表
→ 本学期专业选修建议 → 本学期推荐课表 → 未来学期路径 → 详细依据
→ 未来学期路径 → 选修学分进度 → 数据范围声明
```
