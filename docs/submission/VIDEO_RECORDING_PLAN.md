## 1. 分辨率 / 浏览器 / 窗口（exact）

### 1.1 录制参数

| 项 | 取值 | 说明 |
| --- | --- | --- |
| 录制分辨率 | **1920×1080（16:9）** | 首选；成片不缩放即为最终交付分辨率 |
| 帧率 | **30 fps**（若设备允许用 60 fps） | 页面几乎无动画，30 fps 足够且文件更小 |
| 码率 | 8–12 Mbps（H.264） | 文字为主，码率过低会让小字发糊 |
| 录制区域 | **仅浏览器窗口**（裁到窗口边界） | 桌面、任务栏、通知区、Dock 一律不入镜 |
| 音频 | 48 kHz / 单声道即可 | 与画面同一时间轴录制 |

### 1.2 显示器与浏览器

| 项 | 取值 | 理由 |
| --- | --- | --- |
| 系统显示缩放 | **100%** | 125% / 150% 会让小字发虚并可能触发换行，破坏区块版式 |
| 浏览器缩放 | **100%（Ctrl+0 复位）** | ⛔ 不要用 110%/125% 「放大给评委看」——小字会换行，且与页面断言的行数不一致 |
| 浏览器 | Chrome / Edge 最新稳定版，**单窗口单标签页** | 多标签页容易出现「另一个旧标签仍是 Real 结果」的假象 |
| 窗口尺寸（首选） | 浏览器窗口**最大化**于 1920×1080 显示器（内容区约 1920×950） | 页面按 16 进制的常规宽度排版，四个区块标题都在首屏可视范围内 |
| 窗口尺寸（若显示器 >1080p） | 把浏览器窗口手动调整为 **1920×1080 逻辑像素**，或录制后缩放到 1080p | 直接全屏录 1440p/4K 再缩放，正文字会偏软；建议窗口化到 1920×1080 |
| 浏览器界面清理 | **隐藏书签栏**（Ctrl+Shift+B）、清空地址栏建议、地址栏只出现演示地址 | 书签与历史建议属于隐私风险 |
| 页面地址 | 录制推荐 `http://127.0.0.1:4173`（`npm run build` + `npm run preview`）；备选 `http://127.0.0.1:5173`（`npm run dev`） | `preview` 是生产构建，**不渲染开发调试面板**，画面更干净；两种地址都靠 Vite 把 `/api` 代理到 `127.0.0.1:8000` |

> ⚠️ 用 `npm run preview` 时，**前端构建必须成功**；若构建未通过，就用 `npm run dev`，并在片中**只说事实**：
> 「当前用开发模式录制页面，构建门禁这一步没有通过；这不影响我演示的数据来源标注与诚实拒绝行为。」
> ⛔ 不要说「构建已通过」。

### 1.3 启动顺序（录制前 5 分钟完成，命令与仓库一致）

```powershell
# 终端 A（后端，工作目录 backend/）
cd backend
$env:PYTHONUTF8="1"; python -m uvicorn app.main:app --reload --port 8000

# 终端 B（前端，工作目录 frontend/）
cd frontend
npm install          # 首次
npm run build        # 仅当要用 preview（构建失败则改用下一行）
npm run preview      # 默认 http://127.0.0.1:4173
# 备选：npm run dev  → http://127.0.0.1:5173
```

自检（**不要展示本地绝对路径**）：

- `http://127.0.0.1:8000/health` → `200`；
- `GET http://127.0.0.1:8000/api/v1/mock/demo` → `200` 且响应头含 `X-Data-Source: mock`；
- 浏览器打开 `http://127.0.0.1:4173`，页面出现「演示路线（8 场景）」，**没有**「后端接口连接异常」。

## 4. 鼠标移动与悬停规则（cursor movement）

1. **移动速度**：单次移动 400–700 ms 平滑到位；⛔ 不甩鼠标、不做大幅度来回画圈。
2. **停留即静止**：指针停在**区块标题的左侧或右侧空白处**，不要压在文字上；每次停留至少 1.5 秒。
3. **指向何处**：只指向**区块标题、列名、标签、来源行**；⛔ 不用指针在文字上来回「下划线式」扫动（会造成画面抖动与录屏拖影）。
4. **同类元素**：教学班表头、判定列、风险等级、未决类型标签，均按**从上到下**单向移动，到达最后一项后停住，**不回头**再扫。
5. **点击范围**：只允许点击顶部「演示路线（8 场景）」里的锚点项；⛔ 输入框、勾选框、文件选择、「生成规划（Real Planning）」按钮**一律不点**（本片为模式 1）。
6. **严禁**：不打开 DevTools（F12 / Ctrl+Shift+I）、不打开右键菜单、不点开折叠说明（除非台词明确要求，且展开后主标签仍可见）、不点浏览器扩展图标、不拖拽窗口。
7. **滚轮**：每次滚动**一次性到位**（一格或一个小段落），⛔ 不做「滚上去再滚下来」的微调；滚动时不要同时移动鼠标。
8. **结束时**：鼠标停在页面中部空白处，**不要停在按钮或文字上**，便于剪辑定格。

## 6. 音频清单（audio checklist）

| # | 项 | 标准 | 不合格时 |
| --- | --- | --- | --- |
| 1 | 麦克风 | 优先**领夹麦或头戴麦**；其次 USB 桌面麦（指向嘴部、距 15–25 cm） | ⛔ 不用笔记本内置麦录完整片（键盘与风扇声会被收进去） |
| 2 | 输入电平 | 试录 10 秒，正常说话峰值约 **-12 dB 到 -6 dB**，不爆音 | 调低增益或后退 5 cm |
| 3 | 环境噪声 | 关闭空调/风扇/净化器；关窗；手机静音并移开桌面（震动会被收进去） | 换房间或用短指向麦 |
| 4 | 房间回声 | 避免空房间与硬墙反射；桌面上铺布、靠近衣柜/窗帘 | 若回声明显，缩短麦距 5 cm |
| 5 | 语速 | 约 **5 字/秒**；句末下沉、停顿分明；**披露句与来源声明放慢半拍** | 超时按台词文件的「压缩优先级」砍内容，⛔ 不砍披露 |
| 6 | 呼吸与口水音 | 句间自然换气，不贴麦呼吸；录制前喝水、清口 | 必要时在剪辑中留 1 秒静音过渡 |
| 7 | 口误处理 | **不停机**：停 1 秒 → 从本句开头**整句重念** → 继续。剪辑时保留后半句 | ⛔ 不中途改词、不临时补数据、不说「重来」 |
| 8 | 数据口播 | 所有数字一律「以页面实际显示为准」；⛔ 不口算、不背具体条数 | 说错就当场更正：「以页面为准」 |
| 9 | 试听回放 | 录完后**戴耳机完整听一遍**，检查：有无爆音/齿音、有无漏念披露、有没有与画面不同步、有没有把模式 1 说成模式 2 | 发现问题**整段重录**，不做「拼接式补救」 |
| 10 | 音画同步 | 口播与鼠标动作**不要同时开始**（先说一句再动，或先动再开口，留 0.5–1 秒错位） | 剪辑中对齐关键披露句 |

## 7. 备份录制方案（backup recording plan）

### 7.1 设备与文件备份

| 项 | 方案 |

| 录制次数 | 至少录 **2 遍**完整片；以第 2 遍为准、第 1 遍留作备份 |

### 8.3 录制后逐帧检查（交付前必做）

1. **按段抽查**（六段各看一遍），重点看：区块切换帧、锚点跳转瞬间、鼠标误点、任何闪现的弹窗。
2. **全片加速过一遍**，专门盯：地址栏、输入框内容、页脚、第 2 区披露条、任务栏边缘。
3. **确认披露出现次数 ≥2**：第 2 区顶部标签 + 页脚数据声明各至少一次清晰可见（见 §3）。
4. **确认无「Real」误标**：第 4 区来源行在整片中应为「规划结果：Mock」（模式 1）；若某帧显示 Real，必须能对应到明确口播，否则重录。
5. **确认没有敏感串**：检索素材中不出现真实姓名、学号、成绩、凭据、绝对路径、外部网址。
6. **确认音画完整**：披露句、来源声明、页脚声明在成片中**一句不漏**；结尾 5 秒静默定格保留。
7. 发现任何一处红线问题：**整段重录**，不做模糊处理、不做马赛克补救（马赛克本身也会暴露「这里有问题」）。
