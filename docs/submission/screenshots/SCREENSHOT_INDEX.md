## 这一轮（最终 micro UI）后的界面特征

- **补修确认改为单一主操作**：未确认时显示 `确认可转换`，确认成功后**同一个按钮**变为 `✓ 已确认`，
  再点即撤销（`✓ 已确认` 本身就是撤销入口，不再是两个分开的控件）。
- **专业选修加入同样收敛为单一主操作**：未加入显示 `加入本学期方案`，加入后变为 `✓ 已加入，可撤销`。
- **补修表格改为固定列宽**：7 列（本次规划操作 / 课程名称与编号 / 学分 / 判定状态 / 学期建议 / 先修依赖 /
  认定说明与证据），列与横向分隔线对齐，操作列不再因文案长度撑开而错位。

### 03_确认入口与披露.png
逐条确认入口与其上方披露句，逐字为：

> 下表「待人工确认」项可逐条选择**确认可转换**（基于你的确认、仅用于本次规划；不是学校官方认定结果，也不会修改学校教务系统记录）。

### 04_确认后状态.png

### 04b_已确认按钮状态.png
**本轮新增的关键画面**：确认成功后，同一按钮由 `确认可转换` 变为 `✓ 已确认`，再点即撤销。

> ⚠️ 界面把这类条目放进「已满足」计数，但**标记与披露都表明它只是规划层确认**。
> ⛔ 不得讲成"学校已认定满足"。
