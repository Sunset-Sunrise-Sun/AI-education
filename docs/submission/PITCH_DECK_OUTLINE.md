# 学航·转衔 · PPT 大纲（10 页）

> 用途：给负责竞赛包装的同学做 PPT 用的页面级规划。
> 每页给出：标题 / 核心一句话 / 主要内容 / 建议视觉 / 可用证据 / 不能夸大的地方。
> 建议总时长 5 到 6 分钟讲完，配合 3 分钟现场演示。
> 事实口径以 `MATERIAL_FACT_CHECK.md` 为准，一页速查见 `FINAL_FACT_SHEET.md`。

## 全局视觉建议

- **字号优先**：评委距离远，正文不小于 20pt；
- **一页一个观点**：标题就是结论，正文只放支撑；
- **少用英文缩写**：`MakeupTask`、`CourseOffering` 这类词不进主版面，需要时放在备注里；
- **数据披露不动**：凡是涉及教学班数据的页面，都要保留"南校园 + 深圳校区"的范围说明；
- **配色统一**：建议一个主色 + 一个强调色（用于"待确认"状态），避免每页换风格。

## 01 · 转专业之后，学业路径被打断

| 项 | 内容 |
|---|---|
| **标题** | 转专业之后，学业路径被打断 |
| **核心一句话** | 转专业不是换一个专业名，而是把已经走了两年的路重新接一遍 |
| **主要内容** | 1. 学生带着原专业的已修课程进入新专业<br>2. 新专业的培养方案从第一学期就假设了一套不同的课程顺序<br>3. 中间的落差全部落在学生自己身上<br>4. 这个落差横跨好几个学期，不是一次选课能解决的 |
| **建议视觉** | 一条时间轴：左半段是原专业的已修课程（实心块），右半段是新专业的培养要求（空心块），中间有一段断裂带（用警示色标出）。⛔ 不建议用人物照片或焦虑表情素材 |
| **可用证据** | 真实问卷调研：回收 32 份、有效样本 24 份、有效率 75.0%；问题发生率前三为课程时间冲突 75.0%、课程未开设 62.5%、跨学期规划困难 58.3%；仅 8.3% 表示没遇到明显问题 |
| **⛔ 不能夸大** | 不要写"平均多读一年"这类没有出处的数字；⛔ 不要把这个小样本讲成"市场验证完成"或"需求覆盖率"；⛔ 不得出现任何未在原始答卷中出现的统计数字 |

## 07 · Human-in-the-loop 与可信边界

| 项 | 内容 |
|---|---|
| **标题** | 人决定，系统只给依据 |
| **核心一句话** | 认定权、执行权、以及"信息不足时不下结论"，全部留给人 |
