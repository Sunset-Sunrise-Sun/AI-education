# 学航·转衔 · OPC 决赛 4 分钟演示脚本（逐字台词 + 逐步操作）

> **用途**：决赛 4 分钟演示（现场投屏或录屏）的**可直接照读**台词与**逐步操作**。
> **事实依据**：`docs/demo/COMPETITION_DEMO_SCRIPT.md`（8 场景与既定语术）、`docs/demo/COMPETITION_STARTUP.md`（启动命令与验证清单）、`docs/demo/DEMO_RECOVERY.md`（故障处置）、`README.md`、`frontend/src/App.vue`（页面分区与区块标题）。
> **总时长**：**4:00**（六段）。每段都给出「台词 / 操作 / 预期画面 / 评委收获 / 失败兜底」五件套，并在文末给出「开场 60 秒检查清单」与「计时提示（每段留 5 秒缓冲）」。

## 0. 演示前提（开录前必须确认）

- **默认使用模式 1（Mock 回放）**：页面通过 `GET /api/v1/mock/demo` 回放预置对象，**不运行** Curriculum 与 Planner；第 4 区里的方案变更与风险条目是**人工构造的演示样例**。
- 本模式下**第 1–4 区全部标注为 Mock 演示数据**；第 4 区来源行显示「基础演示数据：Mock · 规划结果：Mock」。
- 第 2 区顶部**固定可见**：「教学班数据：演示快照（Synthetic）」以及「当前为演示数据；Mock模式回放预置结果，计算模式执行实际代码，输入来源需逐项核验。」；页脚有**实现边界**与**数据声明**。
- 只有**操作者本机显式准备了本地输入**时才可切到模式 2（计算模式）：此时由 `POST /api/v1/plan` 执行实际的 Provider 与受限 Planner 代码；但**页面基础展示区仍为 Mock 演示数据**，教学班仍为 Synthetic 快照，**实际执行 ≠ 输入真实**。本脚本默认不切换模式。
- 全片必须与页面一致的能力边界：**LLM / RAG / GraphRAG 未接入**；偏好来自**结构化表单**，没有自然语言解析；正式真实端到端证据等级为 **LEVEL 0**；北校园开课查询是**外部系统阻塞**，不探测、不声称可用。

### ① 0:00–0:30 · 问题

**🎤 exact spoken lines（照读，约 130 字）**

> 「转专业以后，真正的问题不是重新选几门课，而是要重新构建一条能毕业、能执行、风险透明的学业路径。

> 我们的原型叫『学航·转衔』，它把这条链路串起来，并且明确标出：哪些是系统处理的，哪些必须交回给人确认。」

**🛟 fallback if UI / API fails**

## 5. 契约兜底版台词（后端/页面不可用时的 60 秒替代）

> 适用：后端起不来、页面显示「Demo 数据加载失败 / 后端接口连接异常」、或代理不生效导致 404。
> 原则：**如实显示错误 → 不生成替代结果 → 不把 Mock 冒充 Real → 不假装成功**。

**🎤 照读台词**

> 「页面现在显示的是『后端接口连接异常』——它明确告诉我本地服务没有起来，并且它不会在旁边自己编一份数据顶上，这是我们设计上的红线。
> 我用一分钟说清这条链路的契约：后端有三个入口——健康检查、一个**永久只读**的演示回放通道，以及真实规划提交入口。演示回放通道返回的响应头会写明数据来源是 Mock；真实规划入口在输入未就绪时返回 503，错误码是『真实规划链路尚未配置』，**不会回退到 Mock，也不会给一个看起来成功的替代结果**——程序缺陷则是 500，不会被包装成 503 糊过去。
> 数据边界也一并说明：教学班输入是明确标注的 Synthetic 演示快照；页面基础展示区是演示数据；正式的端到端真实数据证据等级目前是 LEVEL 0。
> 我现在重启本地服务，再点页面上的『重新尝试连接』。」

**🖱️ 操作**（任选其一，不要同时做两件）

1. 终端执行：`cd backend` → `$env:PYTHONUTF8="1"; python -m uvicorn app.main:app --reload --port 8000`；页面点「🔄 重新尝试连接」。
2. 或在终端展示两条探针命令的输出（**不要展示本地绝对路径**）：
   - `curl.exe -s -o NUL -w "%{http_code}" http://127.0.0.1:8000/health` → 期望 `200`
   - `curl.exe -i -s http://127.0.0.1:8000/api/v1/mock/demo` → 期望 `200` 且含 `X-Data-Source: mock`

⛔ 兜底期间不得：手工造一份数据、把 503 说成「接口没写 / 网络波动」、声称已经验证过没跑通的场景。
