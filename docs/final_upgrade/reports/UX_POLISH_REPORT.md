## 8. 给非专业读者的六句话

1. **现在能做什么**：打开网页能看到"转专业后还缺几门课"，以及这学期和后面几学期怎么补。
2. **用户会看到什么**：第一屏就是缺口数字；每块内容都按"先看结论、再看依据"的顺序排好了。
3. **AI 调整怎么用**：直接说一句人话（比如"太累，别排周五"），确认一下系统理解得对不对，
   系统算出候选后再确认"用不用"，才可能改方案。
4. **最主要的安全边界**：点"采用"只是本次打开页面期间临时生效，没有保存，也不等于学校选课成功。
5. **怎么运行/测试**：`npm run dev` 起页面；`npx vitest run` 跑 303 个前端测试。
6. **出问题先看什么**：先看页面顶部和区块上的 **Mock / 仅前端预览** 标注，
   再看 AI 面板里的"通道"是"未启用"还是"前端预览"——这两种都不是故障，是如实状态。
